# AI Fasting Recipe Assistant

PoC-застосунок аналізує фотографію продуктів за допомогою Gemini API та пропонує страви з урахуванням вибраних харчових обмежень посту.

## Можливості

- завантаження JPG/PNG;
- мультимодальний аналіз зображення;
- три режими харчових обмежень;
- розпізнавання продуктів, що не відповідають режиму;
- три ідеї страв і детальний рецепт;
- вибір кількості порцій.

## Технології

- Python 3.10+
- Streamlit
- Google GenAI SDK
- Gemini API
- Pillow

## Архітектура

`Користувач → Streamlit → фото + інструкція → Gemini API → рецепт`

## Запуск

1. Створіть API-ключ у Google AI Studio.
2. Скопіюйте `.env.example` у `.env`.
3. Додайте ключ:

```env
GEMINI_API_KEY=your_real_key
GEMINI_MODEL=gemini-2.5-flash
```

4. Встановіть залежності й запустіть застосунок:

```bash
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate      # Windows
pip install -r requirements.txt
streamlit run app.py
```

## Приклад демонстрації

1. Обрати режим «Суворий піст».
2. Завантажити фото овочів, картоплі, грибів або круп.
3. Натиснути «Що приготувати?».
4. Показати розпізнані продукти, три варіанти та рецепт.

## Безпека

Не додавайте файл `.env` або API-ключ до GitHub. Застосунок не надає медичних чи богословських рекомендацій, а використовує режим посту лише як набір харчових обмежень.

## Сфери застосування

- планування домашнього меню;
- зменшення харчових відходів;
- підбір страв за дієтичними обмеженнями;
- освітня демонстрація мультимодального AI.
